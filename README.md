# Netshooter — Godot 4

LAN-шутер на Godot 4. Уровень состоит из одного этажа: сетка 3 × 3 из комнат 8 × 8 м, всего 9 комнат. Центральная комната ведёт в боковые, боковые — в угловые через физические проёмы шириной 2,5 м.

В северной комнате центрального ряда в потолке есть квадратный люк 2,4 × 2,4 м; от него до пола опущена лестница.

Внешние стены оформлены как фасад будущего офисного здания: в каждом внешнем сегменте — большое остеклённое окно 4,2 × 1,4 м с бетонной рамой.

Свет строится на локальных холодных потолочных лампах: центральная и угловые комнаты освещены, а боковые помещения без светильников заметно темнее.

## Запуск

1. Откройте корневую папку проекта в Godot 4.7+ и запустите сцену в эксклюзивном полноэкранном режиме 1920 × 1080. Если дисплей физически не поддерживает 1920 × 1080, ОС выберет его максимальный режим, но игра сохранит внутреннее разрешение 1920 × 1080 и масштабирует картинку.
2. В стартовом меню нажмите «Одиночная игра» для сингла либо «Создать LAN-лобби» для мультиплеера.
3. На других машинах введите локальный IP хоста и нажмите «Подключиться».

Управление: WASD — движение, Shift — бег, Ctrl — приседание, Space — прыжок, V — переключение первого/третьего лица, мышь — обзор, ЛКМ — выстрел, Esc — пауз-меню. Подойдите к лестнице у левого края люка со стороны открытой части проёма и удерживайте W, чтобы забраться наверх; S спускает вниз. В пауз-меню доступны «Продолжить» и «Выйти из игры». Godot синхронизирует игроков и визуальные выстрелы по ENet на порту `7000`; здоровья, попаданий и урона пока нет. При первом запуске разрешите Godot доступ к частной сети в Windows Firewall.

Если подключение не установится за 8 секунд, клиент покажет подсказку проверить IP и разрешить входящий/исходящий UDP-порт `7000` для Godot в Windows Firewall.

## Blender

[Исходная сцена](art/netshooter_house.blend) создаётся скриптом `tools/build_house.py`. Её экспорт GLB хранится в `godot/assets/`; Godot-коллайдеры создаются по той же модульной схеме, чтобы проходы и подъёмы были физически проходимы.
